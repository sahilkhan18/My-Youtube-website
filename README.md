## 📖 About

**Code To Score 018** is a personal educational platform where I share:

- 📘 Subject-wise notes for board students
- 💻 Demo project source codes
- 🧠 Practice coding questions (Python, SQL, etc.)
- 📄 Previous years' board question papers
- 💡 Tips & tricks for scoring well in exams
- 📱 Content shared across my social media platforms

The goal is to make learning accessible, organized, and exam-focused for my students, while also serving as a hub for content from my YouTube channel.

---

## ✨ Features

- ✅ Clean, responsive, and minimal UI
- 🌗 **Dark Mode Toggle** with saved preference (localStorage)
- 📄 **Previous Year Question Papers** section for easy access/download
- 📚 Organized sections for Notes, Projects, Practice Code & Tips
- 📱 Mobile-friendly navigation with hamburger menu
- ⚡ Built with **pure HTML, CSS, and JavaScript** — no frameworks, no dependencies
